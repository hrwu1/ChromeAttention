1. Sidebar Loading Overlay

This simulates the loading indicator shown when extracting a goal from a page or generating a session review.

showLoading('Analyzing page...'); // Simulates 3 seconds of processing setTimeout(() => hideLoading(), 3000);

2. Page Processing Indicator

This simulates the small indicator shown in the top-right corner when the AI is evaluating a page in the background.

showProcessingIndicator(); // Simulates 2 seconds of AI evaluation setTimeout(() => hideProcessingIndicator(), 2000);

3. Sequential Loading States

This demonstrates how the loading message updates during different stages of processing.

showLoading('Extracting page content...'); setTimeout(() => { showLoading('Analyzing page...'); setTimeout(() => hideLoading(), 2000); }, 1500);
